## Overview

This project is designed to feel like a **badge archive** first and a **data source** second.

- The visual badge gallery makes it easy to browse.
- The JSON dataset makes it easy to maintain.
- The repository structure makes it easy to scale.

### Status Language

| Label | Meaning |
|---|---|
| 🟢 **Active** | Current feature or badge |
| 🟣 **Experimental** | Limited to an active Discord experiment |
| 🔴 **Legacy** | Historical badge no longer obtainable |
| ⚫ **Retired** | Feature or badge decommissioned/removed |

## Use the Data

The source of truth still lives in [`data/badges.json`](data/badges.json), with each seeded badge entry containing its own `asset` path.

```python
import json

with open("data/badges.json", encoding="utf-8") as f:
    archive = json.load(f)

for badge in archive["badges"]:
    print(badge["name"], badge["asset"])
```
