## Design reference

The catalog concept was inspired by public badge collections including [PandaDevOfficial/badges-discord](https://github.com/PandaDevOfficial/badges-discord). Its descriptions and asset folder are not copied into this starter.

## Visual asset note

All current starter visuals in `assets/` were created specifically for this repository as preview art, rather than copied badge artwork.
